# A56 To Flagship

This module brings S25FE features to the Galaxy A56.

## Highlights

### Galaxy AI

- Call Assist
- Writing Assist
- Interpreter
- Note Assist
- Transcript Assist
- Browsing Assist
- Photo Assist
- Creative Studio
- Weather Wallpaper
- Now Brief
- Health Assist

### Other

- Live Blur works.
- The launcher has flagship animations.
- The quick center icons have animations.
- S25FE wallpapers are added.

### Camera

- 4K60 partially works. At 1x zoom, the video records at around 40fps. This may be fixed in a future release.
- RAW is working with LEVEL_3 enabled (patched with [Camera-Patcher](https://github.com/TBM13/Camera-Patcher)).

## Requirements

- KernelSU with [meta-overlayfs](https://github.com/KernelSU-Modules-Repo/meta-overlayfs/releases/) is mandatory.

## Warning

- **Please do not use APatch or any other tool that can modify boot partitions. This will cause a soft brick.**

## Install

1. Flash the zip in KernelSU.
2. Then use a soft reboot.
